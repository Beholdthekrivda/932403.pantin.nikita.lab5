# ЛР №5 по веб-технологиям

**Вариант 8: «Кулинар и фуд-блогер»** — DOM и взаимодействие с элементами страницы.

## Требования варианта
- Карточки рецептов: название, список ингредиентов `<ul>`, кнопка «Удалить»
- «Добавить рецепт» — название и ингредиенты (через запятую) запрашиваются через `prompt`
- «Удалить последний» — удаляет последнюю карточку
- Переключение светлой/тёмной темы
- Скрытие/показ блока рецептов
- Проверка существования элементов
- Сохранение состояния в `localStorage`

## Реализация
Страница из ЛР №4 дополнена секцией «Мои рецепты» (`#recipes`) и кнопкой темы в шапке.

- **Поиск элементов.** `getElementById` — кнопки; `querySelector` — контейнер списка и подсказка «рецептов нет»; `querySelectorAll('.recipe-card')` — подсчёт карточек и поиск последней.
- **Манипуляции с DOM.** Карточка собирается через `createElement` (`<article>`, `<h3>`, `<p>`, `<ul>`/`<li>`, `<button>`), текст задаётся через `textContent`, класс — через `className`, `data-id` — через `dataset`; добавление — `appendChild`/`append`, удаление — `remove()`.
- **Тема.** Кнопка меняет класс `theme-light` / `theme-dark` у `<body>`; в `style.css` класс `theme-dark` переопределяет CSS-переменные.
- **Скрытие блока.** Кнопка «Свернуть/Развернуть рецепты» добавляет и убирает класс `hidden` у `#recipes-list`.
- **Обработка ошибок.** Перед работой проверяется наличие всех элементов; если чего-то нет — в консоль пишется `Элемент не найден: <селектор>` и скрипт не выполняется. При пустом списке «Удалить последний» пишет в консоль «Нет рецептов для удаления» и показывает `alert("Список пуст")`. Отмена и пустой ввод в `prompt` обрабатываются.
- **localStorage.** Ключи: `lab5.recipes` (массив рецептов), `lab5.theme` (`light`/`dark`), `lab5.recipesCollapsed` (`true`/`false`). Чтение и запись обёрнуты в `try/catch`, данные при загрузке валидируются. При первом открытии показываются два примера; если пользователь удалил всё, пустой список тоже сохраняется.
